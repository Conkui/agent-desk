## 原因与证据

四个预设节点均使用 OpenCode，模型为 DeepSeek 官方 deepseek-flash。工作流开启编排器创建节点，总数上限为 5。编排器首先通过 OpenCode JSON Schema 格式请求生成计划；OpenCode 将此格式实现为强制工具选择。DeepSeek 原生会话数据库记录 HTTP 400，错误为 `Thinking mode does not support this tool_choice`，不可重试。

## 修复

- DeepSeek 官方 OpenAI 兼容接口的规划阶段使用普通 JSON 文本输出，不设置强制结构化工具选择；随后仍由 PlanSchema 严格检查字段与数量，不从说明文字中猜测计划。
- 规划单独使用一个禁用工具的原生会话，不把禁用掩码传给编排器后续工作会话；保留工作阶段原有权限。
