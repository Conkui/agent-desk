# 画布与节点消息

2026-10-23。React Flow 提供画布和节点交互，Dagre 提供自动布局，Radix Dialog 提供消息弹窗与设置抽屉，react-markdown/remark-gfm 渲染节点消息，ACP Registry 和 acp-router 提供 Agent 名录与探测基础；具体版本、源文件与许可见 third_party/README.md。

工作流打开后进入画布。任务连向编排器，编排器将工作分派到节点，节点结果回传编排器。点击节点显示过程、传入、传出和思考。思考仅记录 CLI 返回的 reasoning part；没有返回时为空。历史数据未记录的节点间消息不会补造。

“编排”展示当前工作流定义，“运行记录”展示所选运行的定义快照与实际节点。任务卡打开任务详情；点击连线可直接查看对应节点的传入或传出。消息支持 Markdown、代码和表格，工具过程默认折叠；只有接近消息底部时才自动跟随新内容。远程图片不自动加载。

编排视图中的节点设置及“工作流设置”打开同一个右侧编辑抽屉，可修改名称、任务、目录、编排器、节点职责与权限，最多预设 12 个节点。保存通过版本号避免覆盖其他窗口的修改，并通过命令 ID 避免重试重复写入。修改不改变已有运行，下一次启动使用新定义。

拖动节点和缩放后的视图保存在当前浏览器本地，以工作流或运行 ID 分开记录；这里只保存坐标与视口，不保存任务、消息或密钥。自动布局重新计算显示坐标，不改变执行顺序或依赖。后台轮询和消息更新不会重置已移动的节点。

工作流列表和详情的历史选择器仅请求运行摘要，选中后才读取该运行消息。画布、消息面板与编辑器按需加载。顶部连接状态栏固定于全局，连接失败时提示当前状态。

编排权限是工作流定义的一部分：canCreateNodes、maxNodes（包括预设节点）以及工具权限。开启创建节点后，服务先取得编排计划并严格校验：DeepSeek 官方 OpenAI 兼容接口使用无工具会话输出 JSON 文本，避免思考模式与强制 tool_choice 冲突；其他供应商继续使用 OpenCode 原生 JSON Schema 输出。校验数量后将新增节点、创建者及事件持久化；按分工执行，再把节点结果交给编排器汇总。新节点沿用编排器的 CLI，当前执行适配器仍只有 OpenCode。预设节点与运行中创建的节点分开保存，下一次运行从原定义重新规划。本版本没有任意节点之间的数据依赖或无限自递归创建。

设备页默认展示真实找到的本机 Agent，展开可查看名录。探测从 PATH、常见用户工具目录以及本项目工具目录找可执行文件，不启动 CLI、不安装名录中的工具。已安装和执行适配状态分开表示。名录不能覆盖所有自定义 CLI，后续可通过补充名录和别名扩展。

验证：模拟测试覆盖规划开关、数量限制、动态节点派发、双向交接、编辑版本冲突和运行快照隔离。实际浏览器完成新增节点、保存、刷新、坐标记忆及消息分类检查；另派发一次简短的 OpenCode + DeepSeek 连通任务并确认结束。该单节点检查不能证明真实多节点结构化规划或手机跨网通过，详细证据见 docs/verification.md。
