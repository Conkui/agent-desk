## 已落地

- 列表支持复制、归档、还原。复制仅创建新的编排配置和节点 ID，不复制运行记录或启动 CLI；归档可还原，正在执行或进程未确认释放时拒绝归档。
- 运行提供“进度与结果”面板，查看节点、待审批、交接记录和最终结果；可以复制、导出 Markdown、补充要求或确认完成。
- 消息草稿按浏览器标签页、运行和节点隔离。关闭再打开时恢复，成功发送后清除。
- 新运行记录规划、执行、汇总阶段。最终结果不再混入规划 JSON。
- 失败后自动释放受管 CLI，保留失败原因。进程释放状态独立保存；未确认结束时阻止重试，释放成功后允许按原运行快照重试。
- 旧后台遗留记录只有在系统确认 PID 不存在时自动清理；存在或无法确认的 PID 不会被终止，避免误杀其他进程。
- 精简空状态、权限开关和 Agent 提示词，用户要求的输出格式优先。
