# 第二版界面交付

日期：2026-10-22。范围：HAPI Web 的会话工作区与进入详情的路径。

> 后续功能迭代已将首页改为「工作流列表 → 工作流详情／会话安排 → 成员对话」。本文下方保留早期会话视觉方案及其验证边界，当前操作以 [Demo 使用说明](demo.md) 为准；真实入口为 `http://127.0.0.1:4181/sessions`，4180 示例预览不是当前 Demo。

## 结构

桌面采用 224px 导航 + 会话正文。首页从第一屏展示会话标题、最近进展、Agent、项目与更新时间。待处理请求优先排列；项目、关键词、Agent 与状态可以组合筛选。首页不再并列展示两套会话列表。

手机按 390px 宽度单独排布：标题允许两行，Agent 与项目放在次要信息行，顶部提供搜索，底部提供会话、待处理、设备。主要操作触控区至少 44 CSS px。会话详情沿用原 HAPI 的返回导航与权限卡片。

待处理页显示请求所在会话及操作类型；点击进入完整对话查看命令和参数，使用原有允许/拒绝机制。当前请求摘要不会被当作完整命令或授权依据。项目中尚无工作流任务的数据模型实现，因此界面准确使用“会话”。

## 状态与边界

- active、工作中、待处理、未运行分别表达存活、活动、请求和未运行事实。
- 已离线会话的残留审批不会作为可处理请求显示。
- 返回列表保留搜索、Agent/项目筛选与滚动位置。
- 没有设备时给出配置入口；没有会话、没有搜索结果、暂时没有待处理请求分别显示对应空状态。
- 设备查询失败不遮蔽会话；刷新失败保留缓存并提示状态可能过期。

## 本地交互预览

预览：`http://127.0.0.1:4180/sessions?token=preview`。

这是独立的 loopback 示例服务，运行真实构建后的 HAPI Web，提供合成的会话、消息与审批响应。它不连接真实 CLI，不执行示例命令，也不读取个人会话或密钥。`preview` 是示例入口，不是个人凭据。关闭该开发进程后预览不可访问。

预览服务及截图位于 `hapi/output/design-v2/`，通过本地 Git exclude 排除。真实 Hub 继续使用原接口与原访问保护。

## 验证

- Web 类型检查、生产构建与 diff 检查。
- 4 个测试文件共 16 项通过，其中新增模块有 10 项。
- 浏览器验证中文搜索、待处理入口、会话详情与原权限卡片。
- 在合成服务中拒绝一个请求后，审批按钮消失，返回列表待处理数量从 2 降为 1；不代表真实 CLI 联调。
- 桌面及 390×700 CSS px 手机视口的视觉检查；手机通过同源 iframe 提供真实窄视口，不是原生手机硬件或软键盘测试。

本次没有执行实际 Agent、手机蜂窝网络验证、模型请求或 GPU 工作。已有低成本通信选型保持在 connectivity.md；界面不再常驻技术说明。
